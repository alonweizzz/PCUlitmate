# PCULTIMATE v0.2.0

![PCULTIMATE](assets/pcultimate-logo.svg)

Windows 10/11 system monitoring dashboard.

## What's new in 0.2
- Redesigned sidebar: Dashboard, System Info, Settings, Updates
- Dark/light themes with saved preference (%APPDATA%\\PCULTIMATE\\settings.json)
- Non-invasive automatic GitHub Releases update check at launch, plus manual check
- Update notification links to official release page. **No automatic downloading or executing installers**; user remains in control.
- Existing CPU, RAM, disk monitoring, hardware details and Windows shortcuts retained.

## Build and install
The [Windows installer workflow](.github/workflows/build-windows.yml) builds PCULTIMATE.exe and PCULTIMATE-Setup.exe using PyInstaller and Inno Setup. Download `PCULTIMATE-Installer` from the successful GitHub Actions run, unzip, and run `PCULTIMATE-Setup.exe`. The installer is unsigned and Windows may warn about unknown publisher.

To run source: `py -m pip install -r requirements.txt`, then `py pcultimate.py`. Source mode requires PNG branding assets generated by `python scripts/render_assets.py` on Windows.

**Releases:** Update checks only discover published GitHub Releases with a newer semantic version tag such as `v0.3.0`. GitHub Actions artifacts are not considered releases; publish a signed or reviewed installer to Releases before users can discover it.

## Privacy
Monitoring stays on the device. Update checks contact GitHub's public API. No telemetry or remote PC controls.
